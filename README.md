# AirWorker (エア・ワーカー) 〜圧倒的進捗偽装ポータル〜

> **「真の休息は、完璧な偽装の上にのみ成立する。」**

現代社会の過酷なプレッシャーに晒されるすべてのデスクワーカーへ捧ぐ――。
『AirWorker』は、あなたが昼寝や動画鑑賞で英気を養っている間、PC画面と周囲の空間に「圧倒的仕事中オーラ」をリアルタイムに生成・付与する総合演出プラットフォームです。

---

## ⚡ 主要機能

- **ハリウッド・モード (Hollywood Mode)**
  - 秒間10,000行が流れる緑色ハッカーコンソール（適当な打鍵で `ACCESS GRANTED` が発動）。
  - 関数が無駄にネストされたセル総数100万超の「超複雑スプレッドシート」。
- **ギット・ゾンビ (Git-Zombie)**
  - 午前2時〜4時を狙い、哀愁と熱意に満ちたコミットをGitHubへ自動プッシュ。
- **ボス・ディテクター (Boss Detector)**
  - Webカメラ映像から怪訝な顔で接近する上司を検知し、**50ms以内**に娯楽画面を隠蔽。
- **猛打タイピング音 & 無限うなずきループ**
  - 青軸メカニカルキーボードの親の仇打ちタイピング音、ため息・微弱な舌打ちのランダム再生。
  - オンライン会議で「神妙に納得する」3秒間ループ映像の自動送出。
- **パニック・ボタン（緊急自爆プロトコル）**
  - Escキー3回連打で即座に履歴消去＆TOEIC学習画面へ緊急ダイブ。
